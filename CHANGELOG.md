# Changelog

## [1.0.0]

- Initial data models for expenses and categories.
- Menu and utility functionality for expense management.
- Expense storage management.

- Expense filtering functionality.
- Expense statistics.
- Monthly and yearly expense reports.
- Custom exceptions and error codes.
- Application logging.
- Project requirements configuration

- Added unit tests for storage functionality.
- Added unit tests for expense filtering.

### Documentation
